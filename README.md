# AegisASI — Attack Surface Intelligence (CBI AGH)

System ciągłego discovery i analizy zmian powierzchni ataku dla dużych sieci (>10 000 adresów IP), tworzony w ramach **HackNation 2026** dla **Centrum Bezpieczeństwa Informacji AGH**.

Pełna specyfikacja techniczna i architektura znajduje się w [SPEC.md](./SPEC.md).
